# archive paradis

a visual collection by posh: a scrapbook photo archive you can sort by colour.

- `index.html` is the website. Text, colours and photos are all stored inside it.
- `page.html` is the same page without the `<html>`/`<head>` wrapper; it is the source of the
  Claude version of the page (where you can add photos from your phone and tap Save).

## Publishing with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)**.
The site appears at `https://rabbit278831-coder.github.io/paradis-archive/`.

## Editing
1. Open the site with `#edit` at the end of the address.
2. Tap **+ add photos** or **✎ edit**, make your changes, and tap **Save**. Your browser downloads a new `index.html`.
3. Replace `index.html` here (**Add file → Upload files**) and commit. The site updates within a minute.

The page holds about 15 MB (roughly 50 photos at web size).
