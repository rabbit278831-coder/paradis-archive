# archive paradis

a visual collection by posh — a scrapbook photo archive you can sort by colour.

The whole site is one file: `index.html`. Text, colours and photos are stored inside it.

## Editing
1. Open the live site with `#edit` at the end of the address (e.g. `https://<your-site>/#edit`).
2. Tap **✎ edit**, change any dashed text, the paper / heart / title colours, add or remove photos,
   change captions and stickers.
3. Tap **Save**. Your browser downloads a new `index.html`.
4. Replace `index.html` in this repository with the new one (GitHub: **Add file → Upload files**, then commit).
   If the site is published with GitHub Pages, it updates within a minute.

Visitors never see the edit button.
